# Support

This is the default support page of every repository of the organization that has none of its own.

- **A bug or an idea** about a repository: open an issue in that repository with one of its forms. Search the existing issues first; the README of the repository may already answer it.
- **A question**, or a private matter that does not belong in a public issue: email <contact@devnto.com>.
- **A security vulnerability**: never an issue. Follow the [security policy](https://github.com/devntoltd/.github/blob/main/SECURITY.md).

Answers come on a best-effort basis; there is no guaranteed response time.
